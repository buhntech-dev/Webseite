👤 Spieler-Rang vergeben

Spielernamen eingeben, Rang wählen und den Befehl für die Aternos-Konsole erzeugen.

/lp user Spielername parent set spieler

🎨 Rang-Prefix setzen

/lp group spieler meta setprefix 1 "&7[Spieler] &f"

Damit Prefixe im Chat und in TAB erscheinen, müssen TAB/Chat-Plugin passend konfiguriert sein.

🛠 Gruppen einmalig anlegen

Wenn die Gruppen noch nicht existieren: Befehle in der Aternos-Konsole einzeln ausführen.

/lp creategroup owner
/lp creategroup admin
/lp creategroup moderator
/lp creategroup supporter
/lp creategroup premium
/lp creategroup vip
/lp creategroup spieler
/lp setdefaultgroup spieler

🔐 Beispielrechte

/lp group admin permission set essentials.fly true

⚠️ Wichtig bei Aternos

Diese GitHub-Pages-Webseite kann Aternos nicht direkt steuern. Aternos stellt dafür keine offizielle öffentliche Verwaltungs-API bzw. RCON-Verbindung bereit. Die Seite speichert keine Zugangsdaten und führt keine Befehle automatisch aus.
  1. Server in Aternos starten und Konsole öffnen.
  2. Den erzeugten Befehl hier kopieren.
  3. In die Aternos-Konsole einfügen (ohne führenden Slash, falls die Konsole ihn nicht akzeptiert).
  4. Enter drücken und die Ausgabe kontrollieren.

Vergib niemals pauschal * oder OP an Teamränge. Erteile nur die tatsächlich benötigten LuckPerms-Rechte. Owner-Rechte nur vertrauenswürdigen Personen geben.
